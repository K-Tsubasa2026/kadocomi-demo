# Kadocomi Demo（学習用UI模写）

カドコミのWebページをReact / TypeScriptで模写した、学習用のデモページです。
※実際のカドコミとは一切関係ありません。

## 概要

React・TypeScript・Viteを使用して実装した学習用Webサイトです。

カドコミのページ構成を参考に、従来のHTML/CSSによる静的な実装だけでなく、Reactのコンポーネント分割、配列を利用した繰り返し表示、Stateを利用した表示切り替え、React Routerによるページ遷移などの学習を目的として制作しています。

また、PC表示だけでなく、768px以下の画面幅に合わせたレスポンシブ対応も行っています。

## デモ

カドコミのトップページを参考に、以下のUIをコンポーネント単位で実装しています。

- ヘッダー
- ナビゲーション
- Heroスライダー
- 新着作品一覧
- ジャンル一覧
- コミック最新刊一覧
- レーベル一覧
- バナー一覧
- アプリ紹介バナー
- フッター
- レスポンシブ対応
- 未実装ページへのアクセス時に表示する404ページ

## 主な機能

### コンポーネント分割

ヘッダー、ナビゲーション、Hero、新着作品、ジャンル、最新刊、レーベル、バナー、フッターなどをそれぞれReactコンポーネントとして分割しています。

ページを複数のコンポーネントに分けることで、役割ごとにTSXとCSSを管理する構成にしています。

### Heroスライダー

トップ部分に複数の画像を表示するスライダーを実装しています。

画像ファイル名を配列で管理し、`map()`を利用してスライドを生成しています。

3秒ごとに自動で次のスライドへ移動し、最後の画像まで到達すると最初の画像へ自然に戻る無限ループ形式にしています。

また、スライダー下部のドットをクリックすることで、任意のスライドへ移動できます。

### 新着作品

新着作品の日付タブと作品一覧を実装しています。

作品データを配列で管理し、`map()`を利用してカードを繰り返し表示しています。

初期状態では一部の作品のみ表示し、「さらに読み込む」ボタンをクリックすると、Reactの`useState`を利用して残りの作品を追加表示します。

### ジャンル・最新刊・レーベル・バナー一覧

ジャンル、コミック最新刊、レーベル、各種バナーをそれぞれ独立したコンポーネントとして実装しています。

複数の同じ形式の要素については、配列と`map()`を利用して繰り返し表示しています。

### レスポンシブ対応

768px以下の画面幅では、各コンポーネントの余白、Gridの列数、画像サイズなどを調整しています。

Heroスライダーについても画面幅に合わせてスライドの移動量を変更し、スマートフォンサイズでも表示できるようにしています。

### React Router

React Routerを使用してページ遷移を管理しています。

トップページは`/`、未実装ページは`/404`としてルーティングしています。

実際の作品詳細、検索、ランキングなどの機能は未実装のため、該当するリンクをクリックした場合は404ページへ遷移します。

### 404ページ

実際の機能を実装していないリンクや存在しないURLへアクセスした場合に、404ページを表示します。

## ローカルでの確認方法

リポジトリをクローンし、必要なパッケージをインストールした後、Viteの開発サーバーを起動します。

```bash
# リポジトリをダウンロード
git clone https://github.com/K-Tsubasa2026/kadocomi-demo.git

# フォルダに移動
cd kadocomi-demo

# パッケージをインストール
npm install

# 開発サーバーを起動
npm run dev
```

起動後、ターミナルに表示されるローカルURLから確認できます。

```text
http://localhost:5173/
```
