# Kadocomi Demo（学習用UI模写）

カドコミのWebページをReact / TypeScriptで模写した、学習用のデモページです。
※実際のカドコミとは一切関係ありません。



## 概要

React・TypeScript・Viteを使用して実装した学習用Webサイトです。




## デモ

カドコミのページ構成を参考に、各種UIをコンポーネント単位で実装しています。




## 使用技術

* React
* TypeScript
* Vite
* React Router
* CSS

## ディレクトリ構成

kadocomi-demo/

## ローカルでの確認方法

```bash
# リポジトリをダウンロード
git clone <リポジトリURL>

# フォルダに移動
cd kadocomi-demo

# パッケージをインストール
npm install

# 開発サーバーを起動
npm run dev
```

## 注意事項

本プロジェクトは個人の学習を目的として作成したものであり、カドコミおよび運営元とは一切関係ありません。

実在するサービスのUIを参考にした学習用デモであり、商用利用や公開配布は想定していません。
